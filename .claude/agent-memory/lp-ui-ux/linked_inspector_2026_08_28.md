# Inspetor de rastreabilidade

- Clique/toque seleciona; edição só abre por “Editar valor”.
- Desktop: painel lateral de 320 px. Mobile/tablet ≤900 px: Modal como bottom sheet.
- “Ver no XML” e “Ver no TXT” trocam aba por ação explícita, expandem ancestrais e restauram foco.
- XML expõe elemento, atributo e texto como treeitems. TXT possui uma única entrada de Tab,
  navegação por setas e lista mobile por ocorrência com alvos de 44 px.
- Confiança: “Declarado no mapeador” e “Melhor estimativa”; limitações sempre visíveis.
- `sectionMappings` é rotulado como relação por seção, sem promessa de campo exato.
