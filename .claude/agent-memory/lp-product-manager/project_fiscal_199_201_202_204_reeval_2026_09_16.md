Em 2026-09-16, após #200/#203/#205/#229 fecharem com evidência real (rodada anterior do mesmo
dia), reavaliei os 4 PBIs remanescentes do Epic #195/#203 ainda em In Validation/In Review:
#199, #201, #202, #204. Todos permanecem abertos — nenhum tinha escopo 100% coberto.

**Método:** li o corpo/aceite de cada issue, cruzei com o código real
(`src/components/mapping-studio/*`, ~2600 linhas de UI, commits `e7f2b1b`/`cc46382`/`c575448`/
`cfef11f` do mesmo dia) e com LayoutParserApi#368 (epic guarda-chuva do gate #200, CLOSED) e
suas filhas #379/#381/#367/#380 (todas CLOSED — perfil fiscal, editor manual, diff granular por
ruleId, diff A×B + cobertura).

**Gaps encontrados (comentário de evidência publicado em cada issue):**

- **#199** (Mapping Studio geral): quase tudo entregue (Sysmiddle read-only badge, boundary
  fail-closed, editor restrito por role, diff A×B/ruleId, WCAG aria). Gap: engine TCL compila
  mas API não tem runner determinístico — loop author+test+publish só fecha para XSL/XSLT.
  Não achei issue de API cobrindo esse runner.
- **#201** (ingestão de pacote fiscal): wizard completo (upload por tipo, progresso, revisão
  incremental, sem localStorage). Gaps: (1) API só devolve hash/tamanho/status de antivírus,
  não "qualidade/conflito/ausência" semântica — depende de API, sem issue aberta; (2)
  inventário de planilha é só exibido, sem passo de **confirmação** de aba/coluna antes de
  interpretar — **implementável só no front**, contrato `ExcelInventoryResult` já existe.
- **#202** (revisão human-in-the-loop): fila completa com os 5 status, autosave ETag/If-Match
  funcionando. Gap: resposta livre a pergunta da IA não é persistida pelo contrato da API
  (limitação documentada na própria UI) — bloqueio de API.
- **#204** (Fiscal Test Lab): execução de fixture individual, XSD, diff, cobertura,
  correlation ID, gate de promoção — tudo entregue. Gap central: **não existe suíte
  versionada** (batch de múltiplos casos), só execução um-a-um; não há contrato nem endpoint
  de API para isso, nem issue aberta — gap real dos dois lados. Layout mobile não foi
  revalidado nesta rodada (delegar a QA/UX antes de fechar).

**Como aplicar:** se o dono quiser progresso adicional só de front sem depender de API, o
único item claramente implementável hoje é o passo de confirmação de inventário de planilha em
#201 (usa contrato já existente). Os demais gaps (#199 TCL runner, #202 resposta livre, #204
suíte versionada, #201 qualidade/conflito/ausência) exigem contrato novo da API — nenhuma
issue de API foi aberta para eles ainda; considerar criar issues cross-repo se o produto
priorizar.
